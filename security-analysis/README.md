## リスク分類基準

各分析で共通して使用するリスク分類基準。

| 深刻度 | 定義 | 対応期限目安 |
|--------|------|-------------|
| **CRITICAL** | 認証バイパス、トークン漏洩、任意コード実行などの重大な脆弱性 | 即時対応 |
| **HIGH** | 権限昇格、機密データ露出、セッション乗っ取りのリスク | 1週間以内 |
| **MEDIUM** | 情報漏洩の可能性、防御層の欠如、設定不備 | 1ヶ月以内 |
| **LOW** | ベストプラクティスからの逸脱、将来的リスク | 次回リリース時 |
| **INFO** | 改善推奨事項、セキュリティ強化の提案 | 任意 |
